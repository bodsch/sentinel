## This session — 14 PRs merged to `main`, each green, each E2E-verified
Don't re-read the diffs; the merge commits (`git log --merges`) are descriptive. Summary by theme:
- **Benchmark vs blackbox_exporter** (PR #1,#2): reproducible harness in `bench/` (`make benchmark`; `bench/main.go` = `benchtool`, separate stdlib-only module `bodsch.me/sentinel/bench`; downloads a pinned blackbox release into `bench/.cache/`). Findings written up in `docs/benchmark-vs-blackbox.md` (Dimensions A per-probe, B loopback scale to N=10000, C real-server phase agreement). Honest conclusion: probe engines comparable; blackbox ~2× CPU (its per-`/probe` wrapper); Sentinel trades that for O(N) memory + O(N) scrape render.
- **Operational metrics** (PR #5,#6): per-target `max_body_bytes` opt-out (`0` = uncapped, rejected in `defaults`); `sentinel_scrape_duration_seconds` render-cost self-metric (via `metrics.NewTimingGatherer`); `metrics.md` → *Operating at scale* (scrape_timeout sizing, "scrape less often" lever, sharding).
- **Histograms** (PR #9): `sentinel_probe_duration_seconds` (all types) + `sentinel_http_ttfb_seconds` are now **Prometheus histograms fed at probe time** (replacing the 0.1 gauges of the same name — a breaking change to those names). Mechanism: a new `scheduler.Observer` hook (`internal/scheduler` — `Observer` interface + `Observers` fan-out) called from `execute()`; `metrics.ProbeDurationObserver` + `httpprobe.TTFBObserver` own the `HistogramVec`s. **This is the mechanism to reuse for any future distribution metric.**
- **HTTP features** (PR #10,#11): custom request headers (`http.headers`, `Host`→req.Host), `basic_auth`/`bearer_token` (mutually exclusive; applied **same-origin only** via `originKey` scheme+host+port — do not regress the redirect leak guard); methods GET/HEAD/POST/PUT/PATCH/DELETE + `http.body` (redirects followed as bodyless GET; GET/HEAD preserved).
- **New protocol** (PR #12): TCP probe `internal/probe/tcp` (`tcp.address` host:port + optional `tcp.expect.banner_regex`, all-must-match, banner accumulated across segments). `sentinel_tcp_connect_duration_seconds`.
- **JSONPath** (PR #13): `http.expect.json` list of `{path, equals}` via **new dependency `github.com/ohler55/ojg`** (real JSONPath, zero transitive deps). `internal/validator/json.go`. Numeric equality (200 == 200.0), multi-match all-must-satisfy, trailing-data + HEAD rejected.
- **Roadmap curation + docs** (PR #4,#7,#8,#14): deferred templates/hot-reload/HTTP-3 as optional; sharding + scrape-interval trade-offs; full docs↔code sync (audit found README/metrics/configuration significantly stale — now fixed).

## The workflow that was used every time (keep doing this)

2. `go fmt && go vet && go test -race ./...` (13 packages) + `-validate` the example config.
3. **E2E verify through the real binary** (run `./bin/sentinel -config <scratch>.yaml`, curl `/metrics`, assert), not just unit tests. Scratchpad configs/servers were used, never committed.
